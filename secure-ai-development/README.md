# Secure Development with AI Coding Assistants - Slidev Presentation

A lightning talk about security best practices when using AI coding assistants like Claude Code.

## Getting Started

To start the slide show:

- `pnpm install`
- `pnpm dev`
- visit <http://localhost:3030>

Edit the [slides.md](./slides.md) to see the changes.

Learn more about Slidev at the [documentation](https://sli.dev/).
